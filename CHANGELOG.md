# Changelog

## [2.2.0] - 2026-11-12

### Added

- **Correction-stream benchmark** (`benchmarks/correction_stream/`), pre-registered before any judge output existed.
  - 240 synthetic calls written from fact vectors; gold labels are a function of the facts, never of a model.
  - Facts checked by a second model family; mismatches adjudicated and published.
  - Arms: few-shot corrections, retrieved corrections, guidelines, gated guidelines, a placebo, ungated rules and gated rules.
  - Results, deviations and every judge cassette are in the repository. CI rebuilds the tables from the cassettes and fails on drift.
  - Result, on Gemma 4 26B with 20 corrections:
    - Rules through the gate turned no right verdict wrong. Few-shot examples broke 19, retrieved examples 10.
    - Retrieved examples were more accurate, 95.0% against 91.6%, so the pre-registered non-inferiority hypothesis failed.
    - 7 of the 20 corrections were misreadings that no rule over the judge's answers can express.
    - DeepSeek V4.1 Flash made no errors on the same calls, so it left nothing to correct.
- README, essay, roadmap and the Pages landing report the benchmark, including the hypothesis that failed.
- A benchmark chart (`docs/assets/benchmark-{light,dark}.svg`) generated by `scripts/figures.py` from the results.

### Fixed

- The LLM judge no longer crashes when a model answers in the wrong shape, for example a bare `"yes"` where an object with a quote was asked for. It reads what it can and notes the problem. The evidence rules still apply: an unquoted "yes" becomes unknown, and a label that needs a quote goes to review.

## [2.0.0] - 2026-11-12

A rebuild. The project is renamed **Precedent** ("pull requests for AI judgment")
and the hackathon code is removed; v1 stays available under the tag `v1-ucws-2026`.
Why: [docs/what-v1-got-wrong.md](docs/what-v1-got-wrong.md).

### Added

- Domain packs (`pack.yaml`, policy clauses with content-hash ids, labelled cases with a held-out split).
- Structured LLM judge for any OpenAI-compatible endpoint; every quote is verified against the case; unverifiable claims are downgraded.
- Heuristic baseline judge with a negation window; record/replay cassettes for real model runs.
- Rules as predicate conditions, applied by code; conflicting rules send the item to review.
- Blocking gate: source correction fixed, examples fire, counter-examples hold, zero regressions, no conflicts, held-out agreement not worse (paired bootstrap CI).
- Rule lifecycle with four-eyes approval, stale-gate detection, versions, revert; append-only SQLite event log with a hash chain and `precedent audit verify`.
- `collections-conduct` pack: 28 calls (18 from v1, 10 new), complete labels, 9 held out.
- `precedent demo`: the v1 keyword rule is blocked with three broken cases; the same correction stated as its real reason passes.
- A recorded run of Gemma 4 26B (local, LM Studio) on the pack, replayed offline; `scripts/results.py` regenerates `docs/results/collections-conduct.md`. Both judges' disagreements are pinned in tests.

### Evidence and integrity

- `precedent evidence RULE`: a self-contained HTML + JSON evidence pack for one rule change. It covers why, what changes, the full gate report with judge quotes, sign-offs with segregation-of-duties checks, limitations, history and chain integrity, and it carries its own hash. Sample packs: `docs/evidence/`. Their log head is anchored in these release notes.
- `precedent audit export`: the complete event population with a chain trailer, so an auditor can sample from it.
- The full gate report is stored in the log. Approval binds the report hash and the gate event, records a rationale, and in the CLI re-performs the gate: if the recorded report is not reproduced exactly, approval is refused. A rule's author cannot record its gate.
- Held-out agreement is reported, not used to decide (it was redundant with `no_regressions`). Changed verdicts get an exact McNemar test, agreement gets Wilson intervals, and a `has_effect` advisory flags rules that fix nothing on the current judge.
- The demo's "real reason" is a narrow new predicate, `supervisor_callback_offered`, rather than a restatement of the rubric item. The Gemma 4 run was re-recorded against it.

### Library and release

- Public API in `precedent.__all__`, `py.typed`, version from package metadata, a `precedent-llm` console script (for `uvx precedent-llm`), PEP 639 licence metadata, Python 3.12–3.14.
- Log format version (`PRAGMA user_version`) and JSON Schemas for rule and pack YAML (`src/precedent/schemas/`).
- Release workflow:
  - verification, build, `twine check`, a wheel smoke test;
  - a CycloneDX SBOM;
  - build-provenance attestations;
  - a GitHub Release;
  - an image at `ghcr.io/fuyoh666/precedent`;
  - PyPI trusted publishing, prepared and gated on the pending publisher.
- CI:
  - a Python 3.12/3.13/3.14 matrix;
  - a packaging job;
  - a zizmor audit;
  - pinned action SHAs;
  - read-only default permissions.

### Hardened after an independent review (Codex)

- Approval is refused if the labelled cases, the judge or the recorded corrections changed since the gate ran (the active rule set was already checked).
- A gate report whose decision contradicts its own blocking checks is refused.
- The gate rejects judge outputs whose case hash does not match their case, outputs from more than one judge, and any accepted correction whose case was removed or changed.
- Counter-examples mean "must not change"; they are compared before and after, not with the label.
- A predicate about one speaker must be quoted from that speaker's lines.
- Lifecycle commands verify the chain first and run read-check-append inside one SQLite write transaction; `audit verify --anchor` checks against an externally recorded head.

### Presentation

- README rewritten as a project page; banner, lifecycle and flip-map figures drawn by `scripts/figures.py` (light and dark), the demo exported as a terminal SVG (`precedent demo --svg`), a social preview rendered from HTML, an essay on the design (`docs/essay.md`), `CITATION.cff`. CI fails if committed numbers or figures drift from the code.

### Removed

- Keyword "Policy Genes", the prosecutor/defender/arbiter mock agents, the FastAPI and Streamlit apps, Qdrant/BGE retrieval, the MCP stub, A2A card and SKILL export, and the hackathon documents.

### Changed

- Labels in the ported v1 cases were revised where they matched the v1 rules rather than the policy (see the pack's LABELING.md).
