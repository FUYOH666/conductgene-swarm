# UCWS Registration

Register ConductGene Swarm on the UCWS portal before the online phase deadline.

## Steps

1. Open [evol.epicconnector.ai](https://evol.epicconnector.ai) and sign in / register.
2. Select **UCWS Singapore 2026** → **AGENT track**.
3. Submit project details:
   - **Name:** ConductGene Swarm
   - **Repository:** https://github.com/FUYOH666/conductgene-swarm
   - **Description:** Human-approved AI conduct QA that remembers supervisor corrections safely. Multi-agent swarm with evidence citations, Policy Genes, rollback, and eval harness.
   - **Demo:** Link to demo video (YouTube unlisted) once recorded — see [demo-video-guide.md](demo-video-guide.md)
4. Confirm CI badge is green on GitHub Actions after first push.
