# UCWS Registration

Register on the UCWS portal before the online phase deadline.

**Model:** one portal project entry, **two tracks** (AGENT + APPLICATION), two GitHub repos described in a unified Description.

## Steps

1. Open [evol.epicconnector.ai](https://evol.epicconnector.ai) and sign in.
2. Edit your project (or create if needed).
3. Select tracks: **AGENT** + **APPLICATION** (do **not** select Deep Research unless you ship a MiroMind `/v1/responses` demo).
4. Copy all fields from [submission/portal-copy.md](submission/portal-copy.md):
   - **Name:** ConductGene Swarm (or ConductGene Swarm & AttestRWA)
   - **Tagline / Description:** unified dual-track text
   - **Repo (form field):** https://github.com/FUYOH666/conductgene-swarm
   - **Demo (form field):** ConductGene YouTube URL
   - **AttestRWA:** repo + demo links inside Description only
5. Upload logo + 3 screenshots from `docs/submission/`.
6. **Resubmit for review** if correcting a previous rejection.
